# Heritage Place Info Page

A single-screen Flutter app for the Flutter Lab SDG-based assignment
(Problem #9, Experiment 2a). It presents the Taj Mahal with a local banner
image, a short description, and a five-star rating.

## Problem statement

Create a clear and attractive heritage/tourist place information page using
Flutter's `Column`, `Row`, `Image`, `Text`, and `Icon` widgets. The page should
work on small screens without overflow and encourage responsible tourism.

## Run the project

1. Install the Flutter SDK and connect an Android, iOS, or web device.
2. From the project directory, run:

   ```bash
   flutter pub get
   flutter run
   ```

3. Run the automated checks with:

   ```bash
   flutter test
   ```

## Asset note

`assets/images/taj_mahal.jpg` is the local Taj Mahal image used by the app.
It was supplied for this project from
[The Wandering Antiquarian](https://thewanderingantiquarian.wordpress.com/2021/02/).
Confirm the image's license and attribution requirements before publishing or
redistributing the app.

## SDG 11 justification

This app supports **SDG 11 (Sustainable Cities and Communities)** by
showcasing heritage and tourist places, encouraging cultural preservation, and
promoting sustainable tourism awareness among users.
